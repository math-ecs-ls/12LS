    Essential Grade 12 LS formulas

    Positive: f(x) ≥ 0 on [a,b] ⇒ A = ∫ₐᵇ f(x) dx.
    Negative: f(x) ≤ 0 on [a,b] ⇒ A = −∫ₐᵇ f(x) dx.
    Changing sign: A = ∫ₐᵇ |f(x)| dx. Split at each zero of f.
    Between curves: A = ∫ₐᵇ |f(x) − g(x)| dx. Split at every intersection.
    Absolute value: |u(x)| = u(x) if u(x) ≥ 0, and −u(x) otherwise.
    Even: f(−x) = f(x); ∫₋ₐᵃ f(x) dx = 2∫₀ᵃ f(x) dx.
    Odd: f(−x) = −f(x); ∫₋ₐᵃ f(x) dx = 0, but geometric area may be positive.

    All area values are in square units. Use exact primitive functions in written exam solutions; the graph gives numerical approximations.
